Privacy Policy

Slow Story English Publisher · Last updated: October 21, 2026

Overview

Slow Story English Publisher ("the tool") is a private command-line application operated by the owner of the YouTube channel Slow Story English. It is used solely to publish and manage that channel's own content through the YouTube Data API. The tool is not offered to the public.

Use of YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Information processed through YouTube API Services is also governed by the Google Privacy Policy (https://policies.google.com/privacy).

Information we access

With the channel owner's explicit authorization through Google OAuth, the tool accesses YouTube API Services on behalf of the owner's own Google account in order to:

  • upload videos and set their metadata (title, description, tags, thumbnail, subtitles, schedule, audience and AI-content disclosures);
  • read and update the owner's channel branding (description, keywords, banner);
  • create playlists and add the owner's videos to them.

The tool does not collect, read or store any information about viewers, subscribers, commenters or other channels.

How information is stored

The OAuth access and refresh tokens are stored only on the channel owner's own computer, in a file readable only by that user. No token, video, metadata or any other data is sent to, or stored on, any server operated by us or by third parties, other than Google's own YouTube API.

Sharing

We do not share any data with third parties. Data obtained through YouTube API Services is used only to publish and manage the owner's channel.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services and is therefore subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google security settings page at https://security.google.com/settings/security/permissions (also reachable at https://myaccount.google.com/permissions). Revoking access immediately invalidates the stored tokens.

Data retention and deletion

The only data the tool keeps is the OAuth token file on the channel owner's computer. It is kept only while the owner uses the tool and is deleted when access is revoked or when the owner deletes the file (~/.config/watch/youtube-token.json). The tool does not store any other API data; if it ever cached API data, that data would be refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies. To request deletion of any data, contact the email below; requests are completed within 7 days.
